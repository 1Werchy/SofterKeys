## English

**What it does:** remap keys and the knob on every layer, lighting (modes, color, brightness), macros stored in the keyboard, profiles that switch automatically per app, and a key test that doesn’t trigger Windows. 11 interface languages.

**Install**
1. Open [Releases](https://github.com/1Werchy/SofterKeys/releases/latest) and download `SofterKeys-<version>.zip`.
2. Unzip it and run **SofterKeys Setup.exe**.
3. Pick the language and folder, click **Install**. Only a shortcut appears on the desktop.

**Updates** come by themselves: when a new version is out, a green bar appears at the bottom of the app — one click and it updates. Profiles are kept.

**Important:** the keyboard can be configured only over a USB cable. In 2.4G and Bluetooth modes everything you set up stays saved in the keyboard and keeps working.

**Supported:** CIDOO QK75 (built in). With a VIA file (.json from the maker): Keychron Q / V / K Pro, other CIDOO with VIA, Epomaker, Akko, MonsGeek with VIA firmware, custom QMK keyboards with VIA. The key test works with any keyboard.

## Українська

**Що вміє:** перепризначення клавіш і ручки на всіх шарах, підсвічування, макроси в пам’яті клавіатури, профілі, що самі вмикаються в потрібній програмі, тест клавіш без спрацьовувань у Windows. 11 мов.

**Встановлення:** відкрий [Releases](https://github.com/1Werchy/SofterKeys/releases/latest), завантаж `SofterKeys-<версія>.zip`, розпакуй і запусти **SofterKeys Setup.exe**.
